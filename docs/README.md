# Repository docs (not published)

Markdown in this `docs/` directory is **reference material** and is excluded from the GitHub Pages build (see `_config.yml`).

To change the public site, edit sources under:

- `pages/docs/` — protocol and guide pages
- `index.md` — landing page
- `_layouts/`, `assets/` — site chrome

Build locally with `make docs-build` from the repository root.
